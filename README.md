# Porters — simp2003

A minimal static portfolio site called "Porters". This branch is intended as a lightweight starter you can preview locally and publish to GitHub Pages.

How to preview locally
1. Clone the repo (if you haven't already) and fetch branches:
   git clone https://github.com/simp2003/new-project.git
   cd new-project
   git fetch origin
   git checkout porters

2. Open `index.html` in the browser, or run a simple server:
   - Python: `python -m http.server 8000`
   - Node: `npx http-server -p 8000`
3. Visit http://localhost:8000

Publish options
- GitHub Pages: publish from the `porters` branch (root) or move files into `docs/` on `main`.
- Vercel / Netlify: connect the repo and point the project to the `porters` branch (static site).
